# Cybersecurity-Dataset-Quality-Evaluator

**数据集多指标质量评估系统 · 1.1.1**

给系统一个网络安全数据集文件夹，自动识别日志、标签、攻击过程说明和防御材料，输出百分制评分与中文报告。

| 评估方面 | 主要看什么 | 总分占比 |
| --- | --- | --- |
| 全面性 | 记录是否可用，攻击和行为覆盖得怎样 | 35% |
| 真实性 | 分层抽查标注是否有行为依据，时间与行为分布是否接近参考数据 | 40% |
| 对抗性 | 攻击过程是否有关联，是否包含可查证的防御行为 | 25% |

## 开始使用

需要 Python 3.9 或以上版本。在项目目录打开终端，安装依赖：

```bash
python -m pip install -r requirements.txt
```

把 `.env.example` 复制为 `.env`，填写模型服务的地址、模型名称和密钥。支持 OpenAI 兼容接口，不限于 DeepSeek；具体填写方法见[使用说明](docs/USAGE.md)。

然后运行：

```bash
python run.py --input "数据集文件夹路径" --output "新的结果文件夹路径"
```

**输入**：直接使用已有数据集文件夹，保留原有文件和子目录。已有标签、攻击过程说明和防御记录一并提供；不需要先按固定字段整理数据，也不用补写没有的材料。

**输出**：结果放在另一个新文件夹，不能与输入文件夹相互包含。完成后打开其中的 **`report.md`**，查看总分、三个方面的分数、各项得分原因和明细。

R01覆盖每个已声明攻击步骤，每步最多抽10条关联记录；未关联步骤的标签每类最多补充10条。A04最多抽40个防御动作。报告公开样本数量、覆盖率和依据，不把抽查结果称为全量正确率。开始语义核验前显示请求批次数，运行中定期显示进度。

A03由模型结合执行证据判断属于哪种ATT&CK缓解措施，A04核验执行与结果是否对应；所有分数由本地公式计算，判断依据留在详细报告中。

系统自动识别已有适配范围内的数据；不能识别或材料不足时会记录原因。**缺少证据的项目记0分，未完成全部数据处理时不出总分。**
